# T01 — Données, variables, populations et échelles de mesure

**Niveau :** L1–L2 · **Durée :** 4–5 h · **Prérequis :** B01–B02.

## Objectifs
Identifier unité statistique, population, échantillon et variable ; distinguer types de variables et échelles de mesure ; choisir des résumés cohérents avec la nature des données.

## 1. Vocabulaire statistique
Une population est l'ensemble des unités visées par l'étude. Une unité statistique est l'élément observé. Un échantillon est un sous-ensemble observé de la population. Une variable associe une valeur ou catégorie à chaque unité. Une observation est une réalisation de cette variable pour une unité donnée.

Il faut distinguer population cible, population effectivement couverte et population échantillonnée : leurs écarts peuvent produire une erreur de couverture.

## 2. Types de variables
- Qualitative nominale : catégories sans ordre (branche, pays).
- Qualitative ordinale : catégories ordonnées (niveau de satisfaction).
- Quantitative discrète : valeurs dénombrables (nombre de sinistres).
- Quantitative continue : mesure sur un continuum (durée, montant, taille).

Une variable numérique codant des catégories n'est pas pour autant quantitative. Le code postal 1000 est une étiquette, pas une quantité.

## 3. Échelles de mesure
L'échelle nominale autorise l'égalité et la différence ; l'ordinale ajoute l'ordre ; l'intervalle permet d'interpréter des différences mais pas les rapports (température Celsius) ; l'échelle de rapport possède un zéro absolu et autorise les rapports (durée, masse).

## 4. Structure des données
Une table rectangulaire associe généralement lignes (unités), colonnes (variables) et cellules (valeurs). Identifier clés, doublons, granularité, unités physiques, dates, devises, modalités manquantes et éventuels identifiants. Une ligne peut représenter une personne, un contrat, une transaction ou un événement : la granularité doit être explicite.

## Exemple
Dans une étude de sinistres auto, une ligne peut représenter un contrat-année ou un sinistre. La fréquence par contrat ne peut être calculée correctement si l'on confond ces deux granularités.

## Exercices corrigés
1. Le numéro de contrat est-il quantitatif ? **Corrigé :** non, c'est un identifiant nominal.
2. Une échelle de satisfaction 1–5 est-elle nécessairement métrique ? **Corrigé :** non, elle est au minimum ordinale ; les écarts égaux ne sont pas garantis.
3. Une table sinistres a une ligne par sinistre. Peut-on lire directement la fréquence annuelle par contrat ? **Corrigé :** non, il faut rapporter les sinistres à une exposition ou à un dénominateur contractuel.
4. Pourquoi documenter la granularité ? **Corrigé :** pour éviter doublons, agrégations erronées et dénominateurs incohérents.

## Erreurs fréquentes
Confondre code et mesure ; traiter des catégories ordinales comme des intervalles sans justification ; oublier unité d'observation ; confondre population cible et population accessible.

## Critères de maîtrise
Décrire précisément population, unité, variable, échelle, unité et granularité d'un jeu de données.
