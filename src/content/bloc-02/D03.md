# D03 — Méthodes de démonstration

**Statut :** Revue interne effectuée · consolidation pédagogique en cours.

**Bloc :** B02 · **Niveau :** L1–L2 · **Durée :** 4–5 h  
**Prérequis :** D01 et D02.

## Objectifs

Construire une preuve directe, utiliser la contraposée, raisonner par contradiction, traiter une équivalence et distinguer preuve et vérification sur des exemples.

## 1. Qu'est-ce qu'une preuve ?

Une preuve est une chaîne finie d'arguments qui établit une conclusion à partir d'hypothèses, de définitions et de résultats déjà admis. Une intuition, un dessin, plusieurs essais numériques ou une simulation peuvent suggérer un résultat ; ils ne démontrent pas une affirmation universelle.

Avant de prouver, identifier précisément : les hypothèses, la conclusion, les domaines des variables et les définitions mobilisées.

## 2. Preuve directe

Pour démontrer $P\Rightarrow Q$, on suppose P vraie et on déduit Q par des étapes justifiées.

Exemple : si n est pair, alors $n^2$ est pair. Par définition, $n=2k$ pour un entier k. Alors $n^2=4k^2=2(2k^2)$ ; le terme entre parenthèses est entier, donc $n^2$ est pair.

## 3. Contraposée

Pour prouver $P\Rightarrow Q$, on peut prouver $\neg Q\Rightarrow\neg P$, car les deux implications sont équivalentes.

Exemple : si $n^2$ est impair, alors n est impair. On prouve la contraposée : si n est pair, $n=2k$, donc $n^2=4k^2$ est pair. La contraposée étant vraie, l'énoncé initial est vrai.

## 4. Contradiction

On suppose la conclusion fausse et on montre que cette hypothèse conduit à une impossibilité logique ou à une contradiction avec les hypothèses.

Exemple classique : $\sqrt 2$ est irrationnel. Supposons $\sqrt2=p/q$ avec p et q entiers premiers entre eux, q non nul. Alors $p^2=2q^2$, donc p est pair ; écrivons p=2k. On obtient $q^2=2k^2$, donc q est pair. p et q ont alors un facteur commun 2, contradiction avec leur coprimalité.

## 5. Équivalence et cas

Pour établir $P\Leftrightarrow Q$, prouver séparément $P\Rightarrow Q$ et $Q\Rightarrow P$. Une preuve par cas est utile lorsque les hypothèses permettent une partition exhaustive : par exemple x est positif ou nul, ou négatif. Les cas doivent couvrir toutes les possibilités et ne pas se contredire si une partition est recherchée.

## 6. Contre-exemple

Pour réfuter une affirmation universelle « pour tout x, P(x) », un seul contre-exemple suffit. Pour réfuter « toutes les observations respectent la règle », il suffit d'une observation valide qui ne la respecte pas. Un contre-exemple doit appartenir au domaine annoncé.

Exemple : « tout nombre premier est impair » est faux ; 2 est un contre-exemple. Le fait que beaucoup de nombres premiers soient impairs ne change rien.

## 7. Comment rédiger une preuve lisible

1. Énoncer ce qui est supposé.
2. Rappeler les définitions utiles.
3. Enchaîner les implications sans saut injustifié.
4. Justifier les opérations (division, racine, logarithme) par leurs conditions.
5. Terminer en reliant explicitement le résultat à la conclusion.

## 8. Exercices corrigés

**1.** Prouver que la somme de deux entiers pairs est paire.  
*Corrigé :* écrire $a=2m$ et $b=2n$. Alors $a+b=2(m+n)$, avec $m+n$ entier.

**2.** Prouver que si n est impair, alors $n^2$ est impair.  
*Corrigé :* écrire $n=2k+1$. Alors $n^2=4k^2+4k+1=2(2k^2+2k)+1$.

**3.** Réfuter « pour tout réel x, $x^2>x$ ».  
*Corrigé :* x=0 donne $0>0$, faux. On peut aussi prendre x=1.

**4.** Démontrer que si n est entier et $n^2$ est divisible par 3, alors n est divisible par 3.  
*Corrigé :* contraposée. Si n n'est pas divisible par 3, son reste modulo 3 vaut 1 ou 2 ; son carré vaut 1 modulo 3. Il n'est donc pas divisible par 3.
