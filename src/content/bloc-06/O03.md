# O03 — Programmation linéaire : géométrie et méthode du simplexe

## Objectifs d’apprentissage
À l'issue de cette unité, l'apprenant doit pouvoir :
- Décrire un polyèdre réalisable ; identifier une solution de base ; expliquer les pivots du simplexe et diagnostiquer les cas particuliers.

**Prérequis :** O01–O02, B03. **Durée :** 5–6 h.

## Forme générale
Un programme linéaire optimise une fonction affine sous contraintes affines. Une forme courante est
$$\max c^Tx\quad\text{sous }Ax\le b,\ x\ge0.$$
La région réalisable est un polyèdre. Si un optimum fini existe, il existe au moins un sommet optimal, même si d'autres points de la face optimale peuvent également l'être.

## Géométrie en deux dimensions
Chaque contrainte définit un demi-plan. La région admissible est leur intersection. Les lignes de niveau de l'objectif se déplacent parallèlement ; la dernière ligne qui touche la région indique l'optimum.

Il faut distinguer sommet, arête et face : un objectif parallèle à une arête peut produire plusieurs solutions optimales.

## Variables d'écart et base
Pour convertir $a^Tx\le b$ avec $b\ge0$ en égalité, on introduit une variable d'écart $s\ge0$ :
$$a^Tx+s=b.$$
Une base correspond à un choix de variables basiques dont les colonnes forment une matrice inversible. Une solution de base est obtenue en fixant les variables non basiques à zéro. Si elle est admissible, elle est une solution de base réalisable.

## Principe du simplexe
Le simplexe passe d'un sommet réalisable à un sommet voisin en améliorant l'objectif. À chaque itération :
1. calculer les coûts réduits ;
2. choisir une variable entrante qui améliore l'objectif ;
3. effectuer le test du rapport minimum pour choisir la variable sortante ;
4. pivoter et mettre à jour la base ;
5. arrêter lorsqu'aucune amélioration admissible n'est possible.

Les conventions de signe des coûts réduits dépendent de la forme du tableau. Les règles de pivot doivent être cohérentes avec la convention retenue. Des règles anti-cyclage, comme Bland, évitent les cycles dans les cas dégénérés.

## Exemple
Maximiser $3x+2y$ sous $x+y\le4$, $x\le2$, $y\le3$, $x,y\ge0$. Les sommets candidats incluent $(0,0)$, $(2,0)$, $(0,3)$, $(2,2)$ et $(1,3)$. Les valeurs correspondantes sont 0, 6, 6, 10 et 9. L'optimum est $(2,2)$, de valeur 10.

## Cas particuliers
Un programme linéaire peut être infaisable, non borné, dégénéré, ou admettre plusieurs optima. Le simplexe peut effectuer des pivots dégénérés sans amélioration stricte de l'objectif. En pratique, la complexité moyenne est souvent favorable, mais le pire cas du simplexe classique est exponentiel.

## Exercices corrigés
1. Ajouter une variable d'écart à $2x+3y\le12$ : $2x+3y+s=12$, $s\ge0$.
2. Si deux sommets distincts ont la même valeur optimale et que l'objectif est linéaire, tout le segment qui les relie est optimal.
3. Un problème non borné ne signifie pas que le solveur a « échoué » : il révèle que la formulation ne limite pas suffisamment l'amélioration de l'objectif.

## Erreurs fréquentes
Oublier les conditions de non-négativité ; appliquer le rapport minimum avec un coefficient nul ou négatif ; confondre optimum local et sommet réalisable ; oublier les cas de dégénérescence.
