# M04 — Hessienne, Taylor multivarié et extrema libres

**Prérequis :** M02–M03 et B04 A06. **Durée :** 4–5 h.

## Hessienne et Taylor
La Hessienne $(H_f)$ est la matrice des dérivées secondes. Si elles sont continues, elle est symétrique. Pour une fonction deux fois continûment différentiable près de (a),
$(f(a+h)=f(a)+\nabla f(a)^Th+\frac12h^TH_f(a)h+o(\|h\|^2))$.
Le terme quadratique décrit la courbure locale.

## Points critiques et classification
Un point intérieur critique vérifie \(\nabla f=0\). Un extremum local intérieur différentiable est critique, mais la réciproque est fausse.

Hessienne définie positive : minimum local strict ; définie négative : maximum local strict ; indéfinie : point selle. Si elle est semi-définie ou singulière, le test est non concluant.

En deux variables, pour $(H=\begin{pmatrix}A&B\\ B&C\end{pmatrix})$, $(AC-B^2>0)$ et $(A>0)$ donnent un minimum ; $(AC-B^2>0)$ et $(A<0)$, un maximum ; déterminant négatif, une selle.

## Exemple
$(f=x^2+2y^2-4x+8y)$. Le gradient s'annule en ((2,-2)). La Hessienne diag(2,4) est définie positive ; c'est un minimum global de valeur (-12).

## Exercices corrigés
1. $(x^2-y^2)$ à l'origine : Hessienne indéfinie, point selle.
2. $(x^2+3y^2)$ : Hessienne définie positive, minimum strict.
3. $(x^4+y^4)$ : Hessienne nulle à l'origine ; test non concluant, mais minimum strict.

**Erreurs :** confondre point critique et extremum ; conclure avec une Hessienne semi-définie ; confondre optimum local et global ; oublier la frontière du domaine.
