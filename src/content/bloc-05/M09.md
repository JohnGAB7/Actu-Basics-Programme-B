# M09 — Équations différentielles linéaires du second ordre et systèmes

**Statut :** Revue interne effectuée · consolidation pédagogique en cours.

**Prérequis :** M08 et B03 (valeurs propres). **Durée :** 5–6 h.

## Équations homogènes
Pour $(ay''+by'+cy=0)$, $(a\ne0)$, l'équation caractéristique est $(ar^2+br+c=0)$. Deux racines réelles distinctes : $(C_1e^{r_1t}+C_2e^{r_2t})$. Racine double (r) : $((C_1+C_2t)e^{rt})$. Racines complexes $(\alpha\pm i\beta)$ : $(e^{\alpha t}(C_1\cos\beta t+C_2\sin\beta t))$.

## Second membre
Pour $(ay''+by'+cy=g(t))$, la solution générale est la somme d'une solution homogène et d'une solution particulière. Les coefficients indéterminés conviennent à certaines formes de (g) ; la variation des paramètres est plus générale. En résonance, l'essai particulier doit être adapté.

Exemple avec second membre : pour $y''-3y'+2y=e^{3t}$, l'équation homogène a pour solution $C_1e^t+C_2e^{2t}$. En cherchant $y_p=Ae^{3t}$, on obtient $(9-9+2)A=1$, donc $A=1/2$. La solution générale est $y=C_1e^t+C_2e^{2t}+\frac12e^{3t}$.\n\n## Oscillateur amorti
$(my''+cy'+ky=0)$, avec $(m,k>0,c\ge0)$. Les racines décrivent les régimes sous-amorti, critique ou sur-amorti. Les unités et signes physiques doivent être cohérents.

## Systèmes linéaires
Pour $(x'=Ax)$, les vecteurs propres donnent des modes $(e^{\lambda t}v)$ lorsque le système est diagonalisable. Pour le système linéaire continu, si toutes les valeurs propres ont une partie réelle strictement négative, l'équilibre nul est asymptotiquement stable ; si au moins une valeur propre a une partie réelle strictement positive, il est instable. Les valeurs propres sur l'axe imaginaire rendent le critère linéaire incomplet. Les matrices non diagonalisables peuvent produire des facteurs polynomiaux en $t$ en plus des exponentielles.

## Exercices corrigés
1. $(y''-3y'+2y=0)$ : $(y=C_1e^t+C_2e^{2t})$.
2. $(y''+4y=0)$ : $(y=C_1\cos2t+C_2\sin2t)$.
3. $(A=\operatorname{diag}(-1,2))$ : un mode décroît, l'autre croît ; origine selle instable.
4. Une solution particulière seule ne donne pas toutes les solutions : ajouter la solution homogène générale.

**Erreurs :** oublier les cas de racines, omettre la solution homogène, négliger les conditions initiales, conclure à la stabilité depuis une seule valeur propre.
