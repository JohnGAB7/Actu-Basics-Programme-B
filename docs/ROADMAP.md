# Roadmap

## Milestone 0 — Repository and product foundation
- [x] Dedicated repository created.
- [x] Product boundaries and architecture documented.
- [x] Assessment-engine requirements specified.
- [x] Editorial and pedagogical standards specified.
- [ ] Select and initialize the frontend stack.
- [ ] Add automated quality checks and contribution workflow.

## Milestone 1 — Premium public learning experience
- [ ] Responsive application shell and navigation.
- [ ] Programme dashboard and block catalogue.
- [ ] Lesson template with math rendering, examples and references.
- [ ] Search, filters and learning-path navigation.
- [ ] Accessibility and browser smoke tests.
- [ ] Deploy a public, read-only learning experience.

## Milestone 2 — Practice and diagnostic experience
- [ ] Typed question schema and question-bank validation.
- [ ] Practice runner with accessible controls.
- [ ] Instant feedback and worked explanations.
- [ ] Diagnostic report mapped to skills.
- [ ] No persistent personal data until backend is configured.

## Milestone 3 — Secure examinations
- [ ] Choose backend and identity provider after privacy review.
- [ ] Learner identity, authorization and private records.
- [ ] Server-issued exam attempts and timing.
- [ ] Server-side answer selection and grading.
- [ ] Autosave, resume and idempotent submission.
- [ ] Result release, correction and audit trail.
- [ ] Security, accessibility and recovery tests.

## Milestone 4 — Learning analytics and mastery
- [ ] Skill graph and prerequisite-aware recommendations.
- [ ] Learning history and mastery criteria.
- [ ] Revision scheduling based on evidence, not opaque scores.
- [ ] Export and deletion controls for learner data.

## Milestone 5 — Programme expansion
- [ ] Integrate reviewed Bloc 1 content and exams.
- [ ] Integrate Bloc 2 (logic, proofs and discrete mathematics) after review.
- [ ] Develop Bloc 3 (linear algebra and vector geometry) progressively.
- [ ] Add statistics curriculum modules as they are reviewed.
- [ ] Add English content after pedagogical translation review.

## Release principles

A milestone is complete only when its acceptance tests pass and the product status is verified in the deployed environment. Planned work must remain clearly labelled.
