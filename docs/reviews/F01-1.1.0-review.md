## 1. Scope reviewed

The review covers the F01 learning objectives, definitions, conventions, explanations, proof sketches, examples, 12 exercises, worked solutions, scope boundaries and references.

The revised unit focuses on:
- number systems and set inclusions;
- rational and irrational numbers;
- decimal expansions and their non-uniqueness;
- elementary set operations;
- order, intervals and endpoint conventions;
- absolute value as distance and elementary distance constraints.

Base conversion and floating-point representation were moved to F08 so that F01 does not duplicate later quantitative-representation content.

## 3. Exercise and correction audit

All 12 exercises and their supplied corrections were independently recalculated.

- Exercise 1: classification of -3, 0, 11/4, √64 and √11.
- Exercise 2: strict inclusion Z ⊊ Q.
- Exercise 3: proof that √3 is irrational.
- Exercise 4: 0.181818… = 2/11.
- Exercise 5: A ∩ B = [0,2], A ∪ B = ]-3,5[, A \ B = ]-3,0[.
- Exercise 6: finite-set union, intersection, difference and complement.
- Exercise 7: interval translation of three inequalities.
- Exercise 8: |x - 4| < 1.5 gives ]2.5,5.5[.
- Exercise 9: distance at most 4 from 72 gives [68,76].
- Exercise 10: strict lower and inclusive upper thresholds give ]0.85,1.10].
- Exercise 11: 1/3 = 0.333… is a rational counterexample to the claim that every infinite decimal is irrational.
- Exercise 12: |r - 1| < 0.02 gives ]0.98,1.02[.

No arithmetic or set-theoretic correction error was identified in this pass.
